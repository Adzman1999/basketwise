# Step 05: Continuous integration

## Goal

Run the repository's current checks on every branch push and pull request so regressions are visible before changes are merged.

## Workflow

The GitHub Actions workflow at `.github/workflows/ci.yml` installs the locked pnpm workspace and runs these independent checks:

- OpenAPI syntax lint for `postman/specs/basketwise.openapi.yaml`.
- Structural lint for the local Postman collection.
- Workspace TypeScript typecheck.
- API tests with Vitest and Supertest.
- Production builds for the API and web packages.

The Postman CLI checks use local files and suppress report events, so they do not need a Postman account, API key, or workspace binding. The workflow has read-only repository permissions and does not deploy or publish API artifacts.

## Local verification

The workflow commands can be run locally:

```sh
pnpm install --frozen-lockfile
postman spec lint postman/specs/basketwise.openapi.yaml --issueType syntax --no-report-events
postman collection lint 'postman/collections/Basketwise API' --fail-severity error
pnpm typecheck
pnpm test
pnpm build
```

CI itself will report a result after this branch is pushed. No remote workflow run has been observed yet.

## Scope

Deployment is not configured. A hosting target and deployment credentials have not been selected, so this workflow only validates changes.
